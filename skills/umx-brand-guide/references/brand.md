# UMX 企业核心身份与品牌知识库

## 1. 公司 / 品牌名称
- **品牌名称**：UMX
- **扩展名称**：UMX Lab
- **中文业务关联**：尤木 / 尤木设计【正式名称待确认】

## 2. 一句话定位
UMX 是一个以铝合金精密结构、模块化节点、互动灯光、声光同步和智能控制为核心的响应式空间硬件品牌。

## 3. 我们不是谁
- UMX 不是传统家具品牌。
- UMX 不是普通铝型材家具。
- UMX 不是电竞家具品牌。
- UMX 不是单纯卖 RGB 灯效的品牌。
- UMX 不是普通家居电商品牌。

## 4. 我们是谁
UMX 是介于家具、消费电子、空间装置和智能硬件之间的新物种。
我们的产品应该被理解为：
- 空间节点
- 情绪硬件
- 响应式家具系统
- 可联动的生活装置
- 年轻高审美用户的空间表达工具

## 5. 品牌使命
让空间响应人。

## 6. 品牌愿景
在未来 3-5 年内，UMX 要成为年轻高审美用户心中最具代表性的响应式空间硬件品牌。

## 7. 核心价值观

### 长期主义
重品牌资产，不重短期流量套利。

### 结构真实
高级感来自真实材料、真实结构、真实工艺，而不是表面装饰。

### 空间响应
产品必须能回应人的行为、声音、触摸、情绪和场景。

### 高审美但不端着
高级，但不老派；年轻，但不廉价；科技，但不冰冷。

### 系统能力优先
UMX 未来的壁垒不是某一个单品，而是产品系统、品牌系统、内容系统、App 系统和交付系统。

# UMX 品牌灵魂与视觉规范

## 1. 品牌灵魂一句话
UMX 是冷硬结构与情绪光场之间的矛盾体：像硬件一样精密，像空间一样有情绪。

## 2. 核心品牌口号
让空间响应你。

## 3. 品牌调性关键词

### 响应式
- 体现方式：声光同步、触控反馈、场景联动、App 控制、空间状态切换。

### 精密硬件感
- 体现方式：铝合金、铝钣金、CNC 连接件、金属外壳、模块节点、参数标注、结构细节。

### 复古未来
- 体现方式：浅色系统、银灰金属、网格、状态灯、旋钮、冷白光、克制 RGB。

### 情绪光场
- 体现方式：音乐变成光、灯光不是装饰，而是空间情绪。夜晚、音乐、影音、聚会、独处时空间状态发生变化。

## 4. 文字风格
UMX 的文字应该：
- 直接、冷静、有判断、有结构感、有一点反叛、不油腻、不像普通广告、不像传统家具品牌。

## 5. 绝对禁止使用的表达与词汇 (Copywriting Redlines)
为了维护 UMX 极致硬核、客观冷静的机械美学，所有宣发、文案和回复中**绝对禁止**使用以下庸俗、泛化的互联网营销词汇：
- 🚫 **全网第一**
- 🚫 **天花板** (替换方案：陈述物理事实。使用具体的航天级材质如 5052 铝合金、CNC 精密铣削工艺或承重力学参数)
- 🚫 **封神**
- 🚫 **高级感拉满**
- 🚫 **氛围感拉满** (替换方案：描述具体的“冷结构与情绪光场”。例如：“由高饱和电光色构成逆光层晕，通过 32px 物理毛玻璃面板漫射出柔和的偏振光影”)
- 🚫 **黑科技满满** / **黑科技** (替换方案：直接写明产品在声、光、电交互系统上的真实技术参数与原理)
- 🚫 **轻奢** (替换方案：用“不妥协的高端美学”或“极简守序”)
- 🚫 **尊贵**
- 🚫 **匠心**
- 🚫 **闭眼入**
- 🚫 **买它**
- 🚫 **绝绝子**
- 🚫 **年轻人的第一件 XXX**

## 6. 视觉语言
UMX 视觉应优先使用：
- 黑白灰、银灰、水银灰、冷白、局部荧光绿、局部紫色、局部 RGB、网格背景、毛玻璃分层、大标题、少文字、强留白、参数化标注、UI 化版式。

# UMX 组织架构与职责边界

## 1. 核心组织原则
UMX 当前不是传统家具公司，而是一个正在从产品品牌走向响应式空间硬件系统品牌的创业公司。
组织协作必须围绕：
- 品牌统一、产品系统化、内容资产化、交付稳定化、市场国际化、AI 工具化。

## 2. 当前核心部门与具体职责

### 创始人 / CEO
- 负责公司最高层战略判断，包括品牌方向、产品路线、美国 DTC 战略、组织调整、关键岗位任命、重大价格策略、长期技术生态。

### 品牌部
- 负责 UMX 是谁、长什么样、不能变成什么。
- 核心职责：品牌定位、视觉系统、语言系统、品牌边界、官网/App/电商/社媒视觉统一、对外重要内容审核。

### 产品研发部
- 负责产品定义、结构设计、打样、工艺、成本和产品系统化。
- 核心职责：新产品定义、产品结构、材料工艺、打样量产、功能体验、成本控制、产品迭代。

### 市场营销部
- 负责把 UMX 的品牌和产品推向市场。
- 核心职责：市场传播、社媒运营、内容选题协同、电商转化、用户反馈、渠道节奏、市场活动、KOL/KOC 合作、美国 DTC 冷启动配合。

- 内部协同：可设置项目协同/执行推进角色，用于跟进任务、排期、会议纪要和跨部门协作。

### 内容部
- 负责把品牌、产品和创始人思考转化为视频、图文和长期内容资产。
- 核心职责：选题、脚本、分镜、拍摄、剪辑、产品故事、品牌纪录、社媒内容资产。

### 交付部

- 核心职责：供应商管理、采购、仓储、发货、安装、售后、质量反馈、包装优化。

# UMX 产品知识库与核心产品线

## 1. 产品总原则
UMX 的产品不是孤立家具，而是响应式空间硬件节点。每一款产品都要判断：
1. 是否具备第一眼震撼感？
2. 是否具备长期情绪氛围？
3. 是否体现铝合金 / 精密硬件 / 结构感？
4. 是否有灯光、声音、触控、App 或空间响应能力？
5. 是否能进入未来 UMX 系统？
6. 是否避免变成普通家具？
7. 是否适合被内容传播？
8. 是否具备高客单价理由？

## 2. 当前核心产品线

### 系统桌
- **定位**：空间控制台 / 工作与娱乐中心节点。
- **状态**：部分完整。需要补图、材质、功能、成本、价格。

### 系统电视支架 (TV STAND)
- **定位**：把电视区域升级为客厅视觉系统。
- **状态**：概念较清楚。需要详细参数。
- **规格限制**：
  - **65in 规格**：物理尺寸 `1630mm × 500mm × 1715mm`
  - **75in 规格**：物理尺寸 `1680mm × 500mm × 1715mm`

### 系统柜
- **定位**：模块化、金属化、可发光、可联动的空间收纳节点。
- **状态**：方向清楚。需要模块规格。

### 音响落地灯
- **定位**：声音、灯光、边几和空间装置的融合体。
- **状态**：概念较完整。需要参数和成本。

### 铝合金感应椅
- **定位**：带人体响应的金属座椅节点。
- **状态**：部分完整。需要图、尺寸、传感器说明。

### 系统床靠背
- **定位**：卧室场景中的响应式硬件节点。
- **状态**：概念阶段。需要重新定义。

### UMX 智能控制 App
- **定位**：UMX 产品系统的控制中心。
- **状态**：方向清楚。需要功能清单和供应商方案。
