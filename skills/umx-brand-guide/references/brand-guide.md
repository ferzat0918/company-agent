## 2. LOGO 使用规范

### LOGO 类型

UMX 品牌包含两套 LOGO 形式：

- **字型 LOGO** — UMX 文字商标
- **图形 LOGO** — X 形核心符号

### 核心 LOGO 图形

LOGO 由三个矢量元素构成：
1. 右上角 `X` 字形（80×80，黑色填充，41 个顶点）
2. 下方左侧 3 个 `Vector` 图形（各 53.4×53.4，黑色填充，分别 24/40/33 个顶点）——组成 UMX 三个字母

### 使用规则

- **禁止：** 拉伸、旋转、加特效
- **留白：** 使用字型 LOGO 与图形 LOGO 时，以字母 X 高度为基准，确保四周留白最少为 1/2X 的距离
- **缩放：** 必须等比例缩放
- **背景色：** 白底黑X / 黑底白X

> 核心符号：2D扁平 图形+字型 LOGO
> 规则：等比例缩放，周围必须保留足够留白空间（不被裁切、不贴字），禁止拉伸、旋转、加特效。
> 常用：白底黑X / 黑底白X

## 3. 色彩体系 / Brand Color

### 主色 / Primary Color

UMX 以黑白灰为品牌主色，极简守序，干净纯粹。让每一件产品都成为空间里的先锋符号，先于时代，归于本质。

| 色名 | 色样 | HEX | CMYK | 用途 |
|------|------|-----|------|------|
| **黑** | ⬛ | #000000 | 0/0/0/100 | 主色 |
| **白** | ⬜ | #FFFFFF | 0/0/0/0 | 主色 |
| **银** | ⬜ | #D3D3D4 | 0/0/0/25 | 辅助主色 |

### 强调色 / Accent Color

荧光绿划破沉寂，荧光紫点亮赛博梦境。克制底色之上，一抹高饱和电光，是属于未来家居的情绪信号。不喧哗，却足够先锋；不浓烈，却一眼记住。

| 色名 | 色样 | HEX | CMYK |
|------|------|-----|------|
| **荧光绿** | 🟢 | #DAFC08 | 25.46/0/86.42/0 |
| **荧光紫** | 🟣 | #7201FF | 78.63/79.07/0/0 |

### 配色使用规范

**主色调使用：**

- 色调：暗调、高对比、冷色倾向
- 光影：金属反光、逆光、锐利阴影
- 质感：哑光、金属
- 当大面积出现时或整体调性，例如网页和店铺，首先以黑白灰为主，图片也以此为基准制作

**强调色使用：**

- 偶尔大面积使用，例如小红书等宣发图，使用可提现产品的颜色（以达到吸睛的目的来使用）
- 当涉及多个产品时，在官网和主流社交媒体宣发时仍使用黑色和银色为主色调

### Frame 4 背景色（样机页）

Frame 4 背景使用了荧光绿 (#DAFC08) 叠加 5% 白色透明层，并带有 Glass 效果（模糊半径 1px）——模拟毛玻璃质感的高饱和绿色面板。

## 4. 字体规范 / Typography

### 英文字体 / EN Font

| 用途 | 字体 | 字重 |
|------|------|------|
| **Heading（标题）** | Roboto | Bold |
| **Body（正文）** | Roboto | Regular |
| **辅助字体（Code）** | Google Sans Code | Bold & Regular |

### 中文字体 / CN Font

| 用途 | 字体 | 字重 |
|------|------|------|
| **Heading（标题）** | MiSans | Bold |
| **Body（正文）** | MiSans | Regular |
| **辅助字体（Code）** | Google Sans Code | Bold & Regular |

### 层级系统 / Hierarchy

| 层级 | 字号 | 字体 | 特征 |
|------|------|------|------|
| **H1** | 64px | Roboto / MiSans Bold | UPPERCASE / Tight（紧密行距） |
| **H2** | 48px | Roboto / MiSans SemiBold | UPPERCASE |
| **H3** | 32px | Roboto / MiSans Medium | UPPERCASE |
| **BODY** | 16px | Roboto / MiSans Regular | — |
| **DATA** | 10px | Google Sans Code Regular | 等宽字体 / 用于数据 |

### 文字规范

- 标题使用全大写（UPPERCASE）
- 英文：Heading 与 Body 均使用 Roboto
- 中文：Heading 使用 MiSans Bold，Body 使用 MiSans Regular
- 等宽/代码场景使用 Google Sans Code
