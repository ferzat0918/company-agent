### 01 / FEEDBACK & REQUESTS / 问题反馈与需求提报

碰到 Bug 或者想要个新功能？以前只能口头说，现在可以直接在系统里提交，管理员看得到、能跟进。

**入口在哪里**

1. 点右上角顶部菜单栏的 `HOME` 旁边——或者随时点左下角你的头像/邮箱
2. 进个人主页，往下滚到 **§03 FEEDBACK & REQUESTS** 卡片
3. 两个按钮：
   - **我要反馈** —— 提交新的反馈/需求
   - **我的反馈** —— 查看你之前提交过的，以及当前处理状态

**怎么用**

点「我要反馈」弹出一个表单：

| 字段 | 怎么填 |
|---|---|
| 标题 | 一句话讲清楚是什么事，比如 "聊天界面下拉框看不见箭头" |
| 详细描述 | 多写一点：什么时候遇到的、复现步骤、你期望是什么样 |
| 附件（可选） | 直接拖文件进去就行，截图最好；支持图片和 PDF |

提交后会出现在「我的反馈」列表里，状态会从 `待处理` → `处理中` → `已完成`。管理员可能在每条下面加备注解释结论。

### 03 / LONG-TERM MEMORY / 长期记忆机制

以前每次新建对话，AI 都不记得你之前说过啥；得反复告诉它"我叫 XX、我是 X 部门、我习惯简洁回答"。现在 AI 能跨对话记住你了。

#### 03-A / AUTONOMOUS MEMORY / AI 自动记忆

聊天过程中，AI 听到你说"我是 HR 部门的"、"我喜欢简洁回答"、"项目代号叫 alpha"这类**长期有用的事实**，会**主动**调用记忆工具存进去。

**你会看到什么**：右下角冒一个**绿色小弹窗**（Toast），比如：

```
✓ 已记住 [USER]
  用户喜欢简洁回答
  [ 撤销 ]
```

**5 秒倒计时**，弹窗自动消失。如果 AI 存错了：

- **5 秒内**点「撤销」→ 立即从你的记忆里删掉
- **5 秒后**没点 → 正式落实

#### 03-B / MANUAL SYNCHRONIZATION / 手动批量总结

聊了一段长对话后，想让 AI 一次性把这次对话里值得记的事都存起来？用这个按钮。

**入口在哪里**：聊天输入框右边、Send 按钮**左边**那个 💾 图标。

**点了之后会发生什么**：

1. AI 自动扫描当前对话历史
2. 找出最多 5 条值得记忆的事实（跳过已经记过的）
3. 一条条调用记忆工具存入，每条都冒一次 Toast（带撤销）
4. 最后 AI 回一句"已记住 N 条。"

**注意**：跟 A 一样，每条都有 5 秒撤销窗口。

#### 03-C / AUTO RECALL / 新对话自动召回

新建一个对话窗口，**什么都不用做**。AI 在第一次回复你之前，已经自动把你的全部记忆都加载进来了。直接问"我是哪个部门的？"AI 答得出来。

#### SECURITY & BOUNDS / 关键安全保障

- **按账号严格隔离**：你的记忆只属于你的账号，别人登录看不到一个字
- **有上限**：用户信息桶 ≤1375 字符、AI 笔记桶 ≤2200 字符，满了 AI 会自己合并/丢旧的，不会无限增长
- **内容安全**：写入前会扫描，挡掉密钥外泄、prompt 注入这类危险内容
- **AI 不会乱存**：工具描述里明确写了"跳过临时任务、跳过容易重新发现的事"
